# Лила

Создана через Pets и выбрана активной. Идентификатор и подтверждение сохранены в pet.json.

spritesheet.png — финальный прозрачный атлас: 73 кадра, девять анимаций и 16 направлений взгляда. Проверки Pets, структуры и качества пройдены. Розовая кайма удалена; предпросмотры построены из финального файла.

previews/ — GIF всех состояний, MP4, цикл взглядов, переход idle-jump-idle и подписанные кадры. qa/ — отчёты, контактный лист, проверки направлений и сравнение краёв до/после. source-workflow/ — исходники, промпты built-in imagegen, сгенерированные полосы, извлечённые кадры и рабочие проверки.

По прямому разрешению пользователя все материалы сохранены локально вместо ChatGPT Library.
