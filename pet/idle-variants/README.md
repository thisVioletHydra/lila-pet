# Варианты простоя

Активный вариант: **body-sway** — мягкое покачивание корпуса, естественное движение груди под свитером, моргание и наклоны головы.

- `breathing/idle.gif` — спокойное дыхание и моргание; дыхание в малом размере очень тонкое.
- `hair-sway/idle.gif` — мягкое движение волос.
- `head-tilt/idle.gif` — наклоны головы и моргание.
- `body-sway/idle.gif` — активный цикл.

![Активный цикл](body-sway/idle.gif)

В каждом варианте есть полный совместимый `spritesheet.png`, исходная полоса, промпт и отчёты. Формат Pets содержит один idle-цикл из шести кадров; четыре варианта не переключаются автоматически. Все остальные состояния и направления взгляда сохранены без изменений пикселей.
