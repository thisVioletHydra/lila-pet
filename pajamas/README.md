# Лила в пижаме

Ночной образ создан и проверен: лиловая пижама, кремовая отделка и мягкие тапочки. Девять анимаций и 16 направлений взгляда.

Финальный атлас: spritesheet.png. Анимации: previews/. Отчёты: qa/. Исходники, промпты и промежуточные кадры: source-workflow/. Идентификатор питомца: pet.json.

Расписание по Бишкеку: с 08:00 дневная Лила, с 22:00 Лила в пижаме. Переключение в обе стороны проверено вручную; первый автоматический запуск ещё не проверен. Материалы сохранены локально по разрешению пользователя.
